About SignFlow

Signing a PDF should be straightforward: open the document, add what you need, and download the result.

Why this project exists

SignFlow began with a personal need for a simple, free way to sign PDFs. It focuses on that everyday task without requiring an account, subscription, installed application, or a document upload to an application server.

You can draw or type a signature, add text and dates, draw on pages, and export a copy. The mobile layout keeps the document central, while desktop provides tools beside the preview.

Who built it

SignFlow is a project by Ben-Ortiz on GitHub. It was developed through an iterative, AI-assisted workflow using ChatGPT Codex, with product feedback, hands-on testing, fixes, and refactoring shaping the app.

For the source code, technical decisions, and development instructions, visit the SignFlow repository.

Designed around confirmation

Pressing Done separates a finished item from a draft. That makes it possible to keep confirmed work in the exported PDF while leaving unfinished additions out. Finish or delete the current item before starting another; drawing has its own Done and Delete drawing controls.

This behavior grew out of testing real editing sequences: adding several signatures, changing pages, moving dates, and saving while something was still being adjusted.

How it works

The interface uses HTML, CSS, and vanilla JavaScript. PDF.js displays pages, pdf-lib generates the edited document, and the browser's Canvas and Pointer Events APIs support signatures and drawing. GitHub Pages hosts the static site.

PDF bytes and annotations are processed in browser memory. An export uses a snapshot so subsequent edits cannot change that in-progress download. See the privacy policy for hosting, library requests, and storage details.

What SignFlow does and does not do

SignFlow adds visible electronic signatures and annotations. It does not edit existing PDF text, provide certificate-backed digital signatures, or determine whether a signature meets a recipient's requirements. Save your work before leaving the page; there is no cloud account or automatic document backup.
