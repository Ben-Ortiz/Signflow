Contact and feedback

Have a question, a suggestion, or a problem with the editor? The public GitHub project is the contact channel for SignFlow.

Report an issue or suggest an improvement

Open SignFlow's GitHub issues →

Search existing issues first. If the problem has not been reported, open a new issue with a short title and the steps needed to reproduce it. GitHub may ask you to sign in to submit a report; no GitHub account is needed to use SignFlow.

Useful details to include

  • Your device and browser, such as Safari on an iPhone or Chrome on a computer.
  • The tool you were using: Sign, Date, Text, Draw, or Save.
  • The exact sequence of actions, what you expected, and what happened instead.
  • Whether the problem happens with a new, non-confidential sample PDF.

For a missing item in an exported PDF, mention whether Done was pressed before saving and whether another item was still unfinished.

Keep private documents private

GitHub issues are public. Do not attach signed contracts, identity documents, personal signatures, passwords, or other confidential information. Use a blank or redacted sample document and a test signature when demonstrating a problem.

This page does not contain a private upload form or inbox. Please do not use a public issue to send a document for someone else to sign.

Help before you report

The signing guide explains confirmation, page changes, drawing sessions, and saving. The privacy policy explains local PDF processing and third-party hosting requests.
